# WLAN Fabric — Public Distribution

This repository is the **public distribution channel** for WLAN Fabric.
Application source code and development history stay in the private
`cyber-armor/wlan-fabric` repository.

**Release status:** the first native OpenWrt APK is under qualification.
There is **no approved downloadable agent package or controller deployment
release yet**. Do not treat historical CI executables as installable packages.

## Planned first release

- Package name: `wlan-fabric-agent`
- Initial compatibility target: OpenWrt **25.12.6**, `ramips/mt7621`
- Format: native OpenWrt **APK v3**, generated by the firmware-matched SDK
- Compatibility: package architecture and runtime ABI verified from the final
  package metadata, not from an AP manufacturer's model name
- Payload: native Rust agent, OpenWrt procd integration and **public** Root CA
  trust anchor
- No device-specific private keys, certificates, identity files or secrets

Once qualified, a GitHub Release will include the actual APK, SHA-256
checksums, public Root CA certificate and a source/SDK provenance record.
Read and verify that release's compatibility and checksum information
**before** installing. Do not substitute an `.ipk`, a raw ELF, or an APK
for another OpenWrt release or architecture.

Controller Docker Compose definitions, published images and the full operator
guide will follow in a separate, qualified release step. Live deployments
must not depend on this repository being reachable to forward wireless
client traffic.

## Public Root CA scope

The public [`root-ca.pem`](root-ca.pem) is the **Dell lab's Smallstep
Root CA certificate only**. Its X.509 DER SHA-256 fingerprint is:

`af06df479673e99ac3bc4b3779f3cb506dbe7b5745eb6898cd0fa50cb35c59d6`

This certificate is safe to distribute, but it is **not** a generic
organization-wide identity for unrelated WLAN Fabric deployments. A fresh
Hetzner or self-hosted controller with a different CA needs its own
explicitly verified trust anchor and appropriately packaged agent release.
Never copy this CA's private key or assume the same trust relationship
exists automatically at a new site.

## Security boundaries

This repository must contain **only public distributable artifacts and
documentation**. Never commit application source, private keys, enrollment
tokens, passwords, API tokens, SSH keys, live `.env` files, or backups.

Enrollment and device identity are provisioned after package installation
under local, protected AP configuration. Public Root CA certificates are
trust anchors, **not** device credentials.

WLAN Fabric is under active development. It is not yet a complete enterprise
wireless control plane or a certified universal OpenWrt package.
